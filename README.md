# 原子習惯｜Atomic Habits

一个以手机使用为优先的个人每日习惯追踪网站。无需注册帐号，资料保存在浏览器中，可自行建立项目、选择当天要执行的内容，并查看月历与完成统计。

## 在线使用

[打开原子习惯](https://bonk4125252.github.io/atomic-habits/)

建议使用 iPhone Safari 开启，然后选择：

**分享 → 加入主画面**

之后可像一般 App 一样从主画面启动。

## 主要功能

- 自订项目：建立、编辑、删除与排序。
- 手动安排今日：每天的今日清单独立，可逐项加入或批量新增。
- 今日追踪：勾选完成状态、查看即时完成比例，也可从今日清单移除项目。
- 月统计：在月历中查看每天的完成比例与项目明细。
- 项目统计：依每天实际加入的项目计算完成率，避免使用固定旧项目。
- 本机保存：勾选与设定会立即保存到浏览器的 localStorage。
- JSON 备份：一键汇出全部资料，也可汇入还原。
- 旧资料相容：保留并读取早期版本的每日记录。

## 排程说明

建立或编辑项目时可以选择：

| 排程 | 行为 |
| --- | --- |
| 每天 | 当天点击「批量新增」时加入今日清单 |
| 指定星期 | 只有符合设定星期时，才会被批量加入 |
| 单次 | 不参与批量新增，需手动点击「新增到今日」 |

排程不会自动修改已经建立的历史清单。每一天保存的是当天实际加入项目的快照，因此之后修改名称、排程或删除项目，不会改变过去的统计。

## 使用流程

1. 到「设定」分页建立需要追踪的项目。
2. 选择每天、指定星期或单次排程。
3. 每天在设定页逐项点击「新增到今日」，或使用「批量新增」。
4. 到「今日」分页勾选完成项目。
5. 在「月统计」与「统计」分页查看结果。

## 备份与还原

在「备份」分页点击「汇出备份」，网站会下载一个 JSON 文件，其中包含：

- 项目设定
- 排程
- 每日清单
- 完成状态

可以把文件存到 iCloud Drive、Google Drive 或其他安全位置。

汇入备份时，网站会先把目前资料保留为浏览器内的安全副本，再以选择的备份文件还原。

> 目前没有自动云端同步。清除 Safari／浏览器的网站资料可能会删除本机记录，建议定期汇出备份。

## 隐私

- 不需要帐号或密码。
- 不会把习惯资料传送到服务器。
- 所有个人资料默认只存在当前浏览器。
- GitHub Pages 只负责提供网站文件，不保存你的习惯记录。

## 技术与部署

项目为单文件静态网站：

- HTML
- CSS
- 原生 JavaScript
- localStorage
- GitHub Pages

主要程序位于 `index.html`。推送到 `main` 分支后，由 GitHub Pages 自动部署。

## 后续规划

资料结构已经使用版本化 JSON，可在取得使用者明确授权后扩充 Google Drive、iCloud 或其他云端备份服务，而不需要重写今日清单与统计逻辑。
